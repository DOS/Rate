1. Trả Lời Câu Hỏi Cốt Lõi: "Backend của Rate xài gì? Có phải Node.js thuần không?"

KHÔNG PHẢI "Node.js thuần chạy script rời rạc". Để vừa phục vụ hàng triệu lượt truy cập đọc trên Web/Extension với độ trễ thấp, vừa chạy AI chuẩn hóa thông số và cào dữ liệu chống chặn (Anti-Bot) mà không làm nghẽn Web Server, Backend của Rate Platform được thiết kế theo mô hình 4-Layer Composable Backend Architecture (Kiến Trúc Backend 4 Tầng Tách Biệt) chuẩn hệ sinh thái DOS:

Layer 1 - Web BFF & Public REST API v1 Repo: DOS/Rate (apps/web)

Tầng Phục Vụ Giao Diện & REST API (Next.js 16.3.8 App Router + Server Data Layer)

  • Server Data Layer (apps/web/src/server/rate/index.ts): Tầng truy vấn Server-only bọc React.cache() chống gọi trùng lặp (Request Deduplication) giữa generateMetadata() và React Server Components (page.tsx).
  • JSON REST API v1 (apps/web/src/app/api/v1/rate/*): Cung cấp HTTP REST endpoints chuẩn cho cả Web Client Islands lẫn Browser Extension Manifest V3:
    • GET /api/v1/rate/products - Lọc, tìm kiếm, phân trang danh sách sản phẩm chuẩn hóa (có Cache-Control: public, s-maxage=60, stale-while-revalidate=300).
    • GET /api/v1/rate/products/[slug] - Trả về chi tiết Master Product, các gian hàng so sánh giá, lịch sử giá 90 ngày, cảnh báo giảm giá ảo, và điểm tín nhiệm JReviews + AI.
    • POST /api/reviews/[id]/vote - Endpoint ghi nhận bình chọn hữuích (Upvote/Downvote) và báo cáo Seeding (Flag) có xác thực Supabase Auth (DOS.Me SSO).
Layer 2 - Open-Core Intelligence & Normalization Service Repo: DOS/Rate (apps/importer + packages/shared-data)

Tầng Trí Tuệ Nhân Tạo, Chuẩn Hóa 10 Nhóm Thông Số & Chống Seeding

  • Runtime & Compiler: Node.js 26 LTS ES Modules + TypeScript 7.0.2 + Zod 3.25.76.
  • Zod 10-Field-Group Schema (packages/shared-data/src/schemas/specs.schema.ts): Chuẩn hóa 10 nhóm thông số kỹ thuật kết hợp cấu trúc PhoneArena (tách riêng 5 cụm camera) và độ sâu GSMArena.
  • 3-Tier Entity Matcher (entity-matcher.ts): Gom nhóm sản phẩm tự động qua 3 bước: Khớp chính xác model_key -> Tìm kiếm mờ pg_trgm -> Xác minh bằng LLM.
  • Multi-Provider AI Engine (ai-spec-enricher.ts & ai-review-analyzer.ts): Kết nối DOS-AI Gateway (api.dos.ai - vLLM Qwen 3.5 27B), Gemini, OpenAI, DeepSeek, Groq qua giao thức chuẩn OpenAI SDK để điền khuyết thông số và chấm điểm rủi ro Seeding/Scam kép (Product Trust Score vs Merchant Risk Score).
Layer 3 - Private Anti-Detect Scraper & Queue Worker Service Repo: DOS/Rate-Services (Private Enterprise)

Tầng Worker Bất Đồng Bộ, Giải Captcha & Xoay Proxy (Cách Ly Hoàn Toàn Khỏi Web Server)

  • Tại sao tách riêng khỏi apps/web? Tác vụ Playwright Chromium, giải Slider Captcha và xoay IP qua mproxy.vn tốn nhiều CPU/RAM và kéo dài 15-60 giây/job. Tách thành Stateful Worker độc lập giúp rate.vn luôn phản hồi dưới 50ms.
  • Atomic Queue Worker (queue-worker.ts): Lấy job từ bảng rate.crawl_jobs bằng cơ chế khóa dòng nguyên tử FOR UPDATE SKIP LOCKED của PostgreSQL (không cần tốn chi phí vận hành Redis/BullMQ riêng), tự động retry với exponential backoff và gọi thẳng Layer 2 để lưu vào Supabase.
Layer 4 - Database, Atomic Queue & In-DB Trigger Engine Repo quản lý Migration: DOS/DOS.Me (Supabase PG17)

Tầng Cơ Sở Dữ Liệu Quan Hệ, JSONB GIN Index & Trigger Tự Động (Supabase Cloud PostgreSQL 17)

  • Schema rate trên Shared Supabase (gulptwduchsjcsbndmua): Quản lý tập trung qua DOS-Me/supabase/migrations/ (CI/CD: preview -> beta -> prod).
  • Two-Tier Product Catalog: Bảng rate.master_products (sản phẩm chuẩn hóa + JSONB specifications 10 nhóm + key_specs) liên kết 1-N với rate.products (listings từng sàn) và rate.price_history.
  • In-Database Triggers (SECURITY DEFINER): Tự động tính toán lại Bayes Rating, tổng hợp điểm đánh giá đa tiêu chí (JReviews style), và tự động ẩn review khi vượt ngưỡng cờ báo cáo cộng đồng (rate.review_votes).
