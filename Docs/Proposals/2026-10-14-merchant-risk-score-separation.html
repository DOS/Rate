Hiện tại cột rate.merchants.risk_score đang bị 2 nguồn khác nhau cùng ghi vào: (1) DOSafe Threat Intel (cảnh báo lừa đảo/phishing bên ngoài) và (2) Rate Review Analyzer (chấm điểm seeding/phá giá từ review sàn). Nếu không tách, một shop lừa đảo bị DOSafe chấm 90 điểm rủi ro chỉ cần bơm vài chục review sạch lên Shopee là hệ thống Rate sẽ ghi đè risk_score xuống còn 15 điểm (làm mất cảnh báo lừa đảo của DOSafe).

1. Bằng chứng hiện trạng trong Database (`gulptwduchsjcsbndmua`)

  • Trong file khởi tạo gốc 20260912120000_init_rate_schema.sql tại DOS-Me:
    • rate.merchants.risk_score INTEGER DEFAULT 0 có ghi chú: "Can be synced from DOSafe threat_intel".
    • View rate.v_product_trust_summary đang đọc COALESCE(ti.risk_score, m.risk_score, 0) AS merchant_risk_score (kết nối với dosafe.threat_intel theo mã băm tên shop).
  • Trong AiReviewAnalyzer.persistAnalysisToSupabase (vừa viết ở Phase 3.1/3.2):
    • Đang cập nhật trực tiếp rate.merchants.risk_score dựa trên tỷ lệ seeding_fake, phá giá bất thường (dump pricing), và tỷ lệ 1-2 sao thật.
  • Dữ liệu thực tế hiện tại: Toàn bộ 4/4 dòng trong rate.merchants đang có risk_score = 0 (chưa bị ghi đè dòng nào của DOSafe).

3. Thiết kế Chi tiết của Phương Án B (Đề xuất chốt)

1. Nguồn DOSafe

Giữ nguyên cột rate.merchants.risk_score và kết nối dosafe.threat_intel. Rate Importer tuyệt đối không ghi vào cột này.

2. Nguồn Rate Review

Ghi vào 3 cột mới trên rate.merchants: review_risk_score (0-100), review_risk_breakdown (JSONB), và review_risk_updated_at.

3. Công thức gộp trên View

Trong rate.v_product_trust_summary: GREATEST(COALESCE(ti.risk_score, 0), COALESCE(m.risk_score, 0), COALESCE(m.review_risk_score, 0)).

Nội dung Migration dự kiến (sẽ tạo PR tại DOS-Me/supabase/migrations/)

ALTER TABLE rate.merchants
  ADD COLUMN IF NOT EXISTS review_risk_score INTEGER DEFAULT 0
    CHECK (review_risk_score >= 0 AND review_risk_score <= 100),
  ADD COLUMN IF NOT EXISTS review_risk_breakdown JSONB DEFAULT '{}'::jsonb,
  ADD COLUMN IF NOT EXISTS review_risk_updated_at TIMESTAMPTZ;

CREATE OR REPLACE VIEW rate.v_product_trust_summary AS
SELECT
  p.id AS product_id,
  p.title,
  p.current_price,
  p.platform,
  p.sold_count,
  m.name AS merchant_name,
  m.is_official,
  ra.authenticity_score,
  ra.pros,
  ra.cons,
  ra.ai_summary,
  GREATEST(
    COALESCE(ti.risk_score, 0),
    COALESCE(m.risk_score, 0),
    COALESCE(m.review_risk_score, 0)
  ) AS merchant_risk_score,
  ti.category AS threat_category,
  COALESCE(ti.risk_score, m.risk_score, 0) AS dosafe_risk_score,
  COALESCE(m.review_risk_score, 0) AS review_risk_score,
  m.review_risk_breakdown
FROM rate.products p
LEFT JOIN rate.merchants m ON p.merchant_id = m.id
LEFT JOIN rate.review_analysis ra ON p.id = ra.product_id
LEFT JOIN dosafe.threat_intel ti
  ON encode( digest(lower(m.name), 'sha256'), 'hex' ) = ti.entity_hash;
