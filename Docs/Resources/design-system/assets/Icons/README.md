# Icons

Bootstrap Icons, as the app uses them through `react-icons/bs` (react-icons 5.7.0). These are the sixteen most used in `apps/web`, 16 x 16 viewBox, single ink `#0f172a` (`rate-fg-primary`). In the app they inherit `currentColor`; when you need another ink, inline the SVG or use it as a CSS mask instead of `<img>`.

- `shield-check`: trust, verified merchant, hero badge.
- `check-circle-fill`: verified review, pros.
- `star-fill`: star rating, in `rate-score-star`.
- `shop`: merchant.
- `cpu`: specs and hardware.
- `search`: search and inspect.
- `code-slash`: developers and API.
- `exclamation-triangle-fill`, `shield-exclamation`: risk, seeding, fake sale, in `rate-risk-danger`.
- `bell-fill`: watchlist and price alerts.
- `arrow-left-right`: compare.
- `graph-up-arrow`: price history.
- `funnel`: filters.
- `arrow-right`: link arrows.
- `trophy-fill`: leaderboard.
- `box-seam`: products and catalog.
