# Design System (`@repo/design-system`)

Design tokens, CSS variables, and shared theme utilities for the **Rate Platform (`rate.vn`)** Open-Core monorepo.

## Stack

- **Frontend**: Next.js 16.3.8 + React 19.3 + Bootstrap 5.3.8 + Tailwind CSS v4
- **Backend**: Supabase PostgreSQL 17 (`rate` schema) + Next.js Server Data Layer (Zero-Strapi 2026)

## Usage

Import `@repo/design-system/styles.css` in your application stylesheet to consume shared CSS custom properties and utility classes.
